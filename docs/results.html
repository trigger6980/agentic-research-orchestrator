What the numbers mean

On the stub backend, content metrics match because both conditions receive the same deterministic text. The decisive signal is verification rate: the multi-agent pipeline always runs a Verifier stage; the single-agent baseline does not. Content-quality deltas require a live LLM (xai / openai / anthropic).

Design claims this run supports

Pipeline correctness

Verification-before-completion is enforced end-to-end. Every multi-agent report is marked verified; every single-agent report is not — offline, without an API key.
